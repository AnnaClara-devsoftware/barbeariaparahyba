Da curiosidade ao código

Um pouco da minha trajetória, o que me move e onde estou construindo minha base como desenvolvedora.

// resumo.json
FormaçãoEng. de Software
FocoBackend & APIs
Também curtoFront-end & Web
Statusem evolução ⌁

Minha relação com tecnologia começou com curiosidade: queria entender como as coisas que eu usava todos os dias realmente funcionavam por trás da tela. Isso me levou até a Engenharia de Software, onde encontrei um espaço para transformar essa curiosidade em prática constante.

Hoje, estudo e pratico programação com foco em desenvolvimento backend, construção de APIs e modelagem de bancos de dados, sem deixar de lado o desenvolvimento web como um todo — porque acredito que entender o ciclo completo de um sistema me torna uma desenvolvedora melhor.

Sou movida por evolução constante: gosto de testar, quebrar, consertar e aprender com cada projeto. Vejo cada linha de código como uma oportunidade de melhorar um pouco mais do que a anterior.

Sistema de Gestão Acadêmica

Problema: estudantes precisavam de um jeito simples de acompanhar disciplinas, notas e frequência sem depender de planilhas soltas.

Solução: uma aplicação web onde o estudante cadastra disciplinas, registra notas e visualiza o próprio desempenho acadêmico ao longo do semestre.

funcionalidades
  • Cadastro e autenticação de usuários
  • CRUD de disciplinas, notas e frequência
  • Cálculo automático de médias e situação
  • API própria para consumo dos dados
